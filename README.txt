
# Build EXE Online - בלי להתקין פייתון אצלך

## איך מקבלים EXE 64bit מוכן בלי להתקין כלום:

1. צור ריפו חדש ב-GitHub
2. העלה את כל הקבצים מהתיקייה הזו
3. לך ללשונית Actions -> תראה Workflow רץ
4. אחרי 2-3 דקות -> Artifacts -> תוריד:
   - renikud-python-exe (כולל פייתון בפנים, ~50MB, עובד מיד)
   - renikud-go-exe (קל, צריך onnxruntime.dll לידו)

## מה ההבדל?
- Python EXE: עובד 100% כולל ניקוד מדויק, לא צריך פייתון מותקן אצל המשתמש
- Go EXE: קל יותר, בלי תלות בפייתון בכלל גם בבנייה, אבל צריך להשלים inference

המומלץ לך עכשיו: תשתמש ב-Python EXE מה-Artifacts - הוא כבר מכיל הכל, אופליין לגמרי.

## שימוש אחרי שהורדת:
renikud_service_x64.exe
-> רץ על :8080
